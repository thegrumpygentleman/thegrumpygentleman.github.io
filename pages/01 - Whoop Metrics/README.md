# Whoop Biometric Analysis Portfolio

## How to Use

### Viewing the Webpage

1. **Download all files** from the outputs folder to the same directory on your computer
2. **Open `index.html`** in your web browser (Chrome, Firefox, Safari, Edge)
3. The webpage will display with all visualizations and interactive elements

### Important: Keep Files Together

For the webpage to work properly, these files must be in the **same folder**:

```
your-folder/
├── index.html
├── Whoop_Biometric_Analysis_Paper.docx
├── whoop_data.csv
├── summary_statistics.csv
├── correlation_matrix.csv
├── whoop_analysis_dashboard.png
└── time_series_overview.png
```

### Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Interactive Animations**: Scroll-triggered fade-ins and hover effects
- **Download Button**: Click "Download Portfolio Package" to get a ZIP file with all materials
- **Professional Layout**: Bootstrap-powered responsive grid system

### Troubleshooting

**Images not showing?**
- Make sure the PNG files are in the same folder as index.html
- Check that filenames match exactly (case-sensitive)

**Download button not working?**
- Ensure you have internet connection (uses JSZip library from CDN)
- Check browser console for any errors
- Try a different browser

**Best viewed in:**
- Chrome (recommended)
- Firefox
- Safari
- Edge

### Files Included

1. `index.html` - Main webpage
2. `Whoop_Biometric_Analysis_Paper.docx` - Complete research paper
3. `whoop_data.csv` - 90-day dataset
4. `summary_statistics.csv` - Statistical summaries
5. `correlation_matrix.csv` - Correlation analysis
6. `whoop_analysis_dashboard.png` - 9-panel visualization
7. `time_series_overview.png` - Time series charts

### Customization

To customize the webpage:
- Colors are defined in CSS variables at the top of the `<style>` section
- Content can be edited in the HTML
- Images can be replaced (keep same filenames)
